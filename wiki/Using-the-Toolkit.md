# Using the Toolkit

## Pick a tab, type values

Choose the tab for the job. Every tab starts with a working example already filled in, so you can see what a result looks like, then change the numbers to yours. Answers update as you type; there is no Calculate button.

## Prefixes

| Type | Means |
| --- | --- |
| `p` | pico, 10⁻¹² |
| `n` | nano, 10⁻⁹ |
| `u` | micro, 10⁻⁶ |
| `m` | milli, 10⁻³ |
| `k` | kilo, 10³ |
| `M` | mega, 10⁶ |

Examples: `16M` is 16 megahertz, `4.7k` is 4,700 ohms, `4k7` is also 4,700, and `115200` is just the number. A capital `M` is mega and a lowercase `m` is milli.

## Dropdowns

Many tabs have dropdowns for the number of ADC bits, the standard resistor series (E6 to E96), or the board family. Pick the one that matches your hardware.

## Code boxes

The ADC Divider tab produces a code box. Press **Copy** to copy it, then paste it into the Arduino IDE, Thonny, or your editor.
